# Pokedex_Go

A [Pokedex](https://pokemon.fandom.com/wiki/Pok%C3%A9dex) [REPL](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop) using the [Go](https://go.dev/) language

Following a tutorial from [boot.dev](https://www.boot.dev/courses/build-pokedex-cli-golang), this pokedex will be a command-line tool to lookup Pokemon using the [PokéAPI](https://pokeapi.co/) resource.

Using [TDD](https://en.wikipedia.org/wiki/Test-driven_development) for this part, and [Go's testing package](https://pkg.go.dev/testing). Read Dave Cheney's blog on [table driven tests](https://dave.cheney.net/2019/05/07/prefer-table-driven-tests).
